# PADRÃO DE NOMES DE ARQUIVOS — Charlie Echo / Jus 9

## Regra geral
Usar nomes de arquivos em português claro, preferencialmente em minúsculas, sem acentos, sem espaços e separados por hífen.

Exemplo:

```text
ia-profissional.html
avatar-profissional-charlie-echo.png
fotografia-charlie-echo-adulta.png
perfis-profissional.json
```

## Substituição oficial
A antiga referência `ia-profissional` foi substituída por `ia-profissional`.

Aplicar o padrão:

```text
ia-profissional.html -> ia-profissional.html
perfis-profissional.json -> perfis-profissional.json
profissional-onboarding-preview.png -> profissional-onboarding-preview.png
mode/m modo "profissional" -> "profissional"
```

## Exceções
Arquivos históricos recebidos com acento, maiúsculas ou espaços podem ser preservados como origem, mas a implementação do site deve apontar para os nomes padronizados.

## Assinatura
Todo arquivo produzido ou alterado deve preservar autoria, origem, assinatura e vínculo com a Jus 9 Tecnologia Jurídica, conforme o tipo de arquivo.

**Software livre não é autoria abandonada.**
